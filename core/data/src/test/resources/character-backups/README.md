# Character backup fixtures

`published-gson-synthetic.json` is synthetic test data shaped like a backup from
the pre-migration Gson format. It contains no real user data. The fixture is
used to verify nested characters, spells, attacks, ability maps, and spell-slot
values. It is not a byte-for-byte export from a specific published APK; an exact
release artifact fixture must be added when that artifact and its mapping are
available.
